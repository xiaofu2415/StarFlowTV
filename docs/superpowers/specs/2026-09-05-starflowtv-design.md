# 星流电视（StarFlowTV）设计规格

日期：2026-09-05
状态：待最终审阅

## 1. 目标

为 TCL 65T8G Max 与小米电视 4X 55 英寸构建一款自用 Android TV 应用。应用打开后直接进入电视直播，提供接近“我的电视”的轻量遥控器体验；影视点播作为二级入口，兼容 TVBoxOS 的完整配置体系。

项目必须支持央视、各省卫视、江西本地、港澳台及海外频道，优先选择经实际检测的 4K 或更高画质线路。直播源失效时能够自动换线并热更新频道配置；播放器本身支持检查新版 APK。

## 2. 项目范围

### 2.1 包含

- 直播优先首页与遥控器操作。
- 频道分组、收藏、台标与 XMLTV EPG。
- 同频道多线路、手动换线、自动换线和线路熔断。
- 真实分辨率、编码、启动速度、稳定性检测。
- M3U、TXT、JSON 与 TVBox 直播配置输出。
- TVBoxOS 影视入口，保留站点、搜索、解析、Spider JAR、QuickJS、播放器和扩展配置能力。
- 直播配置热更新、签名校验、缓存与回滚。
- APK 稳定版/测试版更新检查。
- `armeabi-v7a`、`arm64-v8a`、`universal` 构建。

### 2.2 不包含

- 直播回看与时移。
- 绕过 DRM、账号认证、付费墙或地区限制。
- 在公开仓库提交账号、Cookie、私人 Token 或家庭 IPTV 凭据。
- 后台静默安装 APK；普通 Android TV 安装升级时仍需系统确认。

## 3. 仓库与授权

### 3.1 `StarFlowTV`

- 以 TVBoxOS 为技术底座，沿用其 AGPL-3.0 要求并保留上游声明。
- 重做启动流程和直播首页，使其具备“打开即播放、上下换台、左右换线”的体验。
- 不直接复制授权不清晰的 `lizongying/my-tv` 代码。
- Android 包名为 `tv.starflow.player`。

### 3.2 `StarFlowTV-Sources`

- 维护频道元数据、候选线路、台标、EPG 映射、检测程序与构建产物。
- 初期设为私有仓库；公开源经来源审查后可额外生成安全公开列表。
- 私人字段由本地配置或 GitHub Secrets 注入，不写入版本历史。

## 4. 应用架构

应用由四个边界清晰的模块组成：

1. `live-ui`：直播首页、频道列表、线路菜单、遥控器焦点和状态提示。
2. `live-core`：频道模型、播放会话、多线路排序、失败判定、熔断和恢复。
3. `tvbox-engine`：TVBoxOS 的影视站点、搜索、解析、脚本与播放能力。
4. `update-client`：直播配置热更新、APK 更新检查、校验、缓存和回滚。

直播模块与影视模块分别保存配置和运行状态。影视接口损坏、加载超时或脚本异常不得阻塞直播启动。

## 5. 直播交互

- 冷启动优先加载本地最后可用配置，并恢复上次频道。
- 上下键切换频道；左右键切换线路；OK 键打开频道列表；菜单键打开设置。
- 分类包括央视、卫视、江西、港澳台、海外、4K 和收藏。
- 自动换源发生时显示简短提示；用户可锁定某条线路。
- 每台设备单独保存最近成功线路和解码兼容性结果。
- TCL 优先尝试 4K HEVC；小米电视 4X 实机验证硬解，失败则降级到兼容编码或 1080p。

## 6. 直播源数据模型与筛选

每条线路至少保存：频道 ID、名称、分类、台标、URL、来源页面、来源类型、协议、请求头、地区限制、Token 类型、DRM 状态、编码、宽高、帧率、码率、最近检测时间、成功率、首帧时间和卡顿率。

线路状态：

- `pending`：待验证。
- `verified`：来源明确且检测通过。
- `degraded`：可以播放但质量下降。
- `geo_limited`：仅指定地区可用。
- `isp_only`：仅指定运营商或家庭网络可用。
- `tokenized`：包含动态凭据。
- `rejected`：DRM、持续失效、来源不可接受或无法安全使用。

只有 `verified`、符合当前网络范围的 `geo_limited` 和 `isp_only` 才进入设备播放列表。检测节点需要标记所在网络；海外 GitHub Runner 的失败不能直接判定中国大陆线路失效。

## 7. 真实画质检测

检测器必须读取实际媒体轨道或媒体分片，不能只信任频道名称或 HLS 清单声明。

| 标记 | 最低实际分辨率 |
|---|---:|
| 8K | 7680×4320 |
| 4K | 3840×2160 |
| FHD | 1920×1080 |
| HD | 1280×720 |
| SD | 低于 1280×720 |

检测结果同时记录视频编码、帧率、码率、HDR/HLG、音频编码和声道。HLS 主清单与实际分片不一致时，以实际媒体轨道为准。

线路先通过稳定性门槛，再按画质层级排序。4K 默认优先必须满足：过去 24 小时成功率至少 95%、首帧不超过 8 秒、最近三次均检测为 2160p、当前设备可硬解，并通过 30 分钟连续播放测试。否则默认选择稳定的 1080p。

## 8. 线路评分与自动换源

同一画质层级内采用 100 分评分：可用率 35、稳定性 25、首帧速度 15、设备兼容性 15、音视频质量 10。

默认失败规则：

- 8 秒未收到媒体数据：换线。
- 10 秒无首帧：换线。
- 连续缓冲超过 8 秒：先重连一次。
- 5 分钟内再次长缓冲：换线。
- HTTP 403、404、410：立即换线并要求重新验证。
- 解码不支持或长期有声无画：先尝试备用播放器内核，再换线。
- 用户锁定线路后只在完全播放失败时自动切换。

防抖与熔断：30 分钟内失败 3 次则暂停线路 2 小时；后台连续检测成功 3 次后恢复；换线成功后至少保持 60 秒；单次最多尝试 4 条线路。

全部线路失败时保留频道页，显示重新检测、刷新源和手动选线入口，同时触发一次紧急配置更新。

## 9. 直播配置生成与更新

源仓库生成：

```text
dist/
├── live.m3u
├── live.txt
├── live.json
├── tvbox-live.json
├── epg.xml
├── manifest.json
└── checksums.sha256
```

公网源默认每 6 小时检测并构建一次。应用启动不等待网络，先播放本地缓存，再后台检查配置版本。新配置下载后必须通过 HTTPS、SHA-256、签名、结构校验和核心频道抽查，才可原子替换旧配置。

应用保存最近 3 个配置版本。下载中断、空配置、签名错误、解析错误或抽查失败均不得覆盖当前版本。支持手动恢复上一版。

更新端点按主服务、备用镜像、GitHub Release/Raw 的顺序尝试。某频道全部线路失效时允许获取较小的线路修复包。直播配置与 TVBox 影视配置分别更新，互不覆盖。

## 10. APK 更新

- 每 24 小时检查一次稳定版；用户可选择测试版通道。
- 展示版本、更新说明、大小和发布时间。
- 根据设备架构选择 v7a、v8a 或 universal APK。
- 下载完成后验证 SHA-256 和签名，再进入 Android 系统安装确认页。
- 升级不覆盖收藏、历史、线路偏好和用户配置。
- 更新失败继续运行当前版本，并提供旧版 APK 下载记录。

## 11. 错误处理与安全

- 所有远程更新均设置超时、重试上限和回退路径。
- TVBox 影视引擎延迟初始化，异常不得影响直播模块。
- 远程 JAR/JS 配置由用户主动导入；应用显示来源和更新提示。
- 私人 Token、Cookie 和账号仅存设备私有目录，不写日志、不导出到公开诊断包。
- 诊断导出默认对 URL 查询参数和请求头脱敏。
- 不执行用于绕过 DRM、付费认证或访问控制的逻辑。

## 12. 测试与验收

自动测试覆盖配置解析、频道合并、线路去重、画质检测、评分排序、自动换源、熔断恢复、配置签名、失败回滚、敏感信息扫描和三种 ABI 构建。

| 验收项 | TCL 65T8G Max | 小米电视 4X 55 |
|---|---:|---:|
| 冷启动 | ≤5 秒 | ≤8 秒 |
| 普通频道首帧 | ≤4 秒 | ≤6 秒 |
| 同频道换线 | ≤4 秒 | ≤6 秒 |
| 连续直播 | 4 小时无崩溃 | 4 小时无崩溃 |
| 4K | HEVC 4K 连播 30 分钟 | 实机验证；失败自动降到 1080p |
| 配置断网 | 使用本地缓存 | 使用本地缓存 |
| 错误配置 | 自动回滚 | 自动回滚 |

实机同时检查音画同步、频道切换黑屏、内存增长、断网重连、休眠恢复、遥控器焦点和 APK 升级后的配置保留。

## 13. 交付阶段

1. 建立 `StarFlowTV` Fork、保留授权、完成可复现构建。
2. 改造直播优先启动与 my-tv 风格交互。
3. 实现多线路、评分、自动换源和设备偏好。
4. 建立 `StarFlowTV-Sources` 数据模型、检测器和配置构建。
5. 接入配置热更新、镜像、校验和回滚。
6. 接入 APK 更新检查和 Release 工作流。
7. 保持并隔离 TVBox 完整影视入口。
8. 完成自动测试与两台电视实机验收。

## 14. 成功标准

- 两台目标电视均可安装并使用遥控器完成所有核心操作。
- 默认进入直播，影视接口故障不影响直播。
- 核心频道拥有至少一条已验证线路；优先线路失效后可自动恢复播放。
- 真实 4K 标记无伪报，设备不兼容时可靠降级。
- 无网络或远程配置损坏时仍可使用最后可用配置。
- 直播源和 APK 均能独立更新，用户数据在升级后保留。
